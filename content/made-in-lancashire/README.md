# Made in Lancashire features

One Markdown file per real feature, named `<slug>.md`, with this front matter.
Only businesses that have approved their write-up go here. The hub shows the
three newest as Recent features, and the full grid appears once there are
more than three.

```yaml
---
slug: business-name
business_name: Business Name
town: Preston
category: Bakery
featured_on: 2026-11-03        # YYYY-MM-DD
hook: a short phrase that reads after "featured for"
story: |
  First short paragraph.

  Second short paragraph.
in_their_words: Their own line.
address: 1 High Street, Preston
map_url: https://www.google.com/maps/search/?api=1&query=...
opening_hours: Tuesday to Saturday, 9am to 5pm   # optional
website: https://...
instagram_handle: theirhandle
instagram_post_url: https://www.instagram.com/p/...
photo: /made-in-lancashire/features/business-name.jpg
logo: /made-in-lancashire/features/business-name-logo.png
video:          # optional, a 9:16 mp4
video_poster:   # optional
placeholder: false
---
```
